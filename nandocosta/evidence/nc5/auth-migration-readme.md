## Scope and limits

The probe uses three generated synthetic devices and the actual GORM Instance, Message and Label models. It stores different per-instance configuration, webhook, synthetic token, event flags, proxy and client settings. No `.env`, production database, production session, WhatsApp account or outbound WhatsApp client is used.

It hashes every row and the definitions of all legacy columns in 19 populated tables: `whatsmeow_device`, `whatsmeow_identity_keys`, `whatsmeow_pre_keys`, `whatsmeow_sessions`, `whatsmeow_sender_keys`, `whatsmeow_app_state_sync_keys`, `whatsmeow_app_state_version`, `whatsmeow_app_state_mutation_macs`, `whatsmeow_contacts`, `whatsmeow_chat_settings`, `whatsmeow_message_secrets`, `whatsmeow_privacy_tokens`, `whatsmeow_nct_salt`, `whatsmeow_lid_map`, `whatsmeow_event_buffer`, `whatsmeow_retry_buffer`, `instances`, `messages`, `labels`.

There are three rows in each table except prekeys (nine) and the shared LID map (four). The same peer, chat and message IDs are reused across devices with different values, and API assertions verify per-device isolation, including PN/LID fallback. Device keys are generated by the library; Signal session, sender-key, account-identity and buffer payloads are synthetic opaque storage fixtures. This verifies storage integrity and compatibility of the exercised APIs, not a real paired Signal exchange, WhatsApp reconnection, send/receive or every upstream protocol behavior.

The two upstream migrations are additive and declare compatibility with v8+: [v15 companion meta nonce](https://github.com/tulir/whatsmeow/blob/54038813c47f3f351eb6fcaafab0e1b99d676850/store/sqlstore/upgrades/15-companion-meta-nonce.sql) adds `whatsmeow_device.companion_meta_nonce`; [v16 WASA root secret](https://github.com/tulir/whatsmeow/blob/54038813c47f3f351eb6fcaafab0e1b99d676850/store/sqlstore/upgrades/16-wasa-root-secret.sql) adds `whatsmeow_chat_settings.wasa_root_secret_id`. Both have `TEXT NOT NULL DEFAULT ''`. Old-code access was executed rather than inferred from those comments alone. Compatibility here means returning to the tested nc.4 store access on schema16 without reverting SQL; it is not a general downgrade guarantee.

Only SHA256 digests, row counts, schema version and booleans are emitted. Database errors are sanitized to operation and error type. The ownership manifest stores digests only.

## Clean sequence

The seven stages below completed in 8.5 seconds using the precompiled binaries. They must run sequentially on this database. Do not rerun seed or new-fields against the completed fixture; use verify for additional checks.

```powershell
$probeStages = @(
    @{n='01-nc4-seed';sdk='nc4';mode='seed';image='nandocosta/evolution-go:0.7.2-nc.4-verify'},
    @{n='02-nc4-baseline';sdk='nc4';mode='verify';image='nandocosta/evolution-go:0.7.2-nc.4-verify'},
    @{n='03-nc5-upgrade';sdk='nc5';mode='verify';image='nandocosta/evolution-go:0.7.2-nc.5-dependencies'},
    @{n='04-nc5-new-fields';sdk='nc5';mode='new-fields';image='nandocosta/evolution-go:0.7.2-nc.5-dependencies'},
    @{n='05-nc4-read-schema16';sdk='nc4';mode='verify';image='nandocosta/evolution-go:0.7.2-nc.4-verify'},
    @{n='06-nc4-save-schema16';sdk='nc4';mode='rollback-write';image='nandocosta/evolution-go:0.7.2-nc.4-verify'},
    @{n='07-nc5-after-return';sdk='nc5';mode='verify';image='nandocosta/evolution-go:0.7.2-nc.5-dependencies'}
)
foreach ($probeStage in $probeStages) {
    $probeResult = docker run --rm --network evogo-homolog-nc5 --label codex.owner=evogo-nc5-20261104 --mount "type=bind,source=$probeRoot/build/auth-probe-bin,target=/probe-bin,readonly" -e EVOGO_TEST_RUN=evogo-nc5-20261104 -e "EVOGO_PROBE_MODE=$($probeStage.mode)" -e 'EVOGO_TEST_POSTGRES_DSN=<fixture-postgres-dsn>' --entrypoint "/probe-bin/$($probeStage.sdk)" $probeStage.image
    $probeCode = $LASTEXITCODE
    $probeResult | Set-Content -LiteralPath "$probeRoot/nandocosta/evidence/nc5/auth-$($probeStage.n).json" -Encoding utf8
    if ($probeCode -ne 0 -or !($probeResult | ConvertFrom-Json).passed) { throw "Probe stage $($probeStage.n) failed" }
}
```
